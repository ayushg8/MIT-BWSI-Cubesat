MuraltZ

A CubeSat that decides what is worth sending home.

Raspberry Pi flight software that only takes a picture when the spacecraft is pointed at the ground and holding still, scores every frame for quality on board, and downlinks the best ones first over a link slow enough that choosing is mandatory. Everything below runs the same thresholds as the real code.

    03 / Imaging gate

    When is the camera allowed to fire?

    Two conditions, both required. Nadir lock engages under 45 degrees and holds until the angle passes 55, so the camera does not flicker at the boundary. The gyro rate must stay under 1.0 rad/s. Drag the sliders.

    04 / Downlink

    A link too slow to send everything

    The link is throttled to 1,200 bytes per second, which matches a 9600 baud radio. One 60 second window gives a 72,000 byte budget. The queue sends P1 first, then P2, then P3, and stops at the first image that does not fit. The real code sleeps one real second per chunk; this plays it back faster. The queue is the six best accepted captures at 640 x 480, with their real JPEG sizes. They are ranked by the gate's combined score (novelty fixed at 1.0). The P1/P2/P3 labels are illustrative: real tiers come from novelty against the coverage grid, which needs a live pass.

    05 / Architecture

    The parts that keep it alive

    Three background systems run beside the state machine. Full write-up in docs/ARCHITECTURE.md.

    WATCHDOG

    A daemon thread. If the main loop stops petting it for 30 s, it saves recovery state and restarts the process with os.execv. Downlink pets it every chunk so a long transfer is not mistaken for a hang.

    • Timeout30 s
    • Check interval5 s
    utils/watchdog.py

    THERMAL

    CPU temperature is read from sysfs. Above 70 C the capture interval doubles. Above 80 C the spacecraft drops to safe mode: camera off, no imaging or downlink, commands still accepted.

    • Warning70 C
    • Critical80 C
    • Check interval10 s
    utils/thermal.py / states/safe_mode.py

    COMMAND LISTENER

    A daemon thread on a TCP port reads newline-delimited JSON from the ground station. Known commands go into a thread-safe queue the state machine drains at safe points. Anything else is NACKed.

    • Port5001
    • Accepted commands11
    comms/command_listener.py

    06 / Honest limits

    What this is not

    An educational prototype. The numbers on this page are designed behavior from the code, plus the gate results above. There are no flight results here.

    Blur threshold20.0 is an uncalibrated placeholder, flagged as such in config.py. Laplacian variance depends on image resolution, so the right value has to be set against the real imaging surface.
    No yawThe IMU has no magnetometer. The software tracks pitch and roll for nadir pointing but not yaw.
    Wi-Fi, not UHFWi-Fi stands in for a flight radio. The 1,200 byte/s throttle reproduces the rate of a 9600 baud link.
    Offline analysisTerrain segmentation and route planning exist in the repo and run in tests. They are not wired into the flight loop.
    SimulatorsThe sections above are visualizations of the flight logic in JavaScript. They are not hardware footage or telemetry.
